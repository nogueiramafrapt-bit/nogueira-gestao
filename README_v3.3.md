# TacoControl Pro Alpha v3.3

## Pausas e descansos — primeira versão indicativa
- Novo ecrã para resumir condução, pausas explicitamente registadas e maior bloco de condução.
- Verificação indicativa de sequências de condução superiores a 4h30 quando não é identificada uma pausa válida nos registos.
- Estados distintos para informação, atenção, possível ocorrência e dados insuficientes.
- Ligação direta a partir do ecrã de importação do tacógrafo.
- Testes unitários básicos do analisador.

## Limitações importantes
Esta versão não certifica conformidade legal. A lógica de pausas ainda não valida toda a sequência regulamentar de 15+30 minutos, todos os descansos diários/semanais, compensações, condução em equipa ou exceções. A interpretação depende de os dados de origem estarem completos e corretamente normalizados. Ficheiros binários DDD/TGD/C1B não devem ser considerados descodificados só por serem reconhecidos.
