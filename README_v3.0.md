# TacoControl Pro — Alpha v3.0

## Análise histórica de 56 dias

A v3.0 acrescenta uma camada de análise histórica dos 56 dias anteriores, com calendário diário, totais e indicação de dias sem dados.

### Objetivo

Organizar a informação importada antes da aplicação das regras de condução, descanso e trabalho.

### Fluxo

DDD/CSV/JSON → atividades importadas → timeline → janela de 56 dias → resumo diário → conformidade → relatório.

### Segurança dos dados

A ausência de uma atividade não é considerada automaticamente uma infração. Dias sem dados são marcados como incompletos para revisão.

### Limitação

A funcionalidade é Alpha e não substitui o tacógrafo oficial, a descarga oficial do cartão nem a validação pelas autoridades.
